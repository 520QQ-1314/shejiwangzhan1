7.1 三步快速验收

步骤 1：单源测试

打开浏览器到 http://127.0.0.1:5000，点 ⚙ 确认 Worker 已配置 → 搜 branding → 在 chip 区单独点 Dribbble → 应该能加载到粉色徽章的卡片。同理验证站酷、UI中国。

步骤 2：收藏几张图

随便收藏 5~10 张不同来源的图（点详情页里的 ❤️ 收藏）。

步骤 3：测试下载

点右上角 ❤️ → 进入收藏夹 → 你会看到顶部多了一条工具栏：
001_dribbble_xxx.jpg
002_pinterest_xxx.jpg
003_zcool_xxx.jpg
...
README.md   ← 内含每张图的完整元数据
步骤 4：测试多选下载

点工具栏的 "✓ 多选" → 卡片右上角出现圆圈 → 点几张图（圆圈变红勾） → 点 "下载选中"。
